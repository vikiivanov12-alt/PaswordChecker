# Password Strength Checker

This project is a simple Python tool that evaluates password strength.
It checks for:
- length
- uppercase letters
- lowercase letters
- digits
- special characters

Finally, it provides a score from 0 to 5 and a text-based security level.

## How to run it
1. Ensure you have Python 3 installed.
2. Run the file:
   python PasswordChecker.py
3. Enter a password when prompted by the program.
